# ANCHOR

ANalysis of agentiC workflows via HistOry and pRovenance

## 📌 Overview

ANCHOR is a framework for capturing and analyzing the provenance of multi-agent workflows using an interaction-centric approach.

The project focuses on representing how agents interact over time, enabling traceability, reproducibility, and deeper analysis of emergent behaviors in complex systems.
